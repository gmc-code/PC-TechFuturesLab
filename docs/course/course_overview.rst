====================================
Course overview
====================================

Welcome to **TechFuturesLab**. In this course you will be a **creator** of technology, not just a user of it.
You will learn how computers work and how to stay safe online, build your own augmented reality (AR)
experience, and write Python programs with buttons, boxes and menus.

Learning intentions
--------------------

By the end of this course I will be able to:

* explain how hardware and software work together, and how they keep data safe
* protect my accounts and personal information online
* design and build an augmented reality experience using images I have edited in Photoshop
* plan an algorithm using pseudocode and flowcharts, and test it
* write Python programs that use variables, selection, loops, functions, lists and dictionaries
* build and change a Python app with a graphical user interface (GUI) using Tkinter

Course at a glance
-------------------

The course runs for one semester (16 weeks).

       authentication, phishing and scams.

     - 9 weeks
     - Print and input, variables and f-strings, algorithms, selection, iteration, functions,
       lists, dictionaries and Tkinter GUI apps.

Grades
~~~~~~~

Tasks are graded from **A+** (highest) down to **NP**. If you hand in a task but it does not meet the
set criteria, it is reported as **UG** (ungraded). Summative tasks (other than exams) below a C standard
must be resubmitted.

Victorian Curriculum
---------------------

This course covers these Victorian Curriculum 2.0 Digital Technologies content descriptions (Levels 9–10).

.. list-table::
   :header-rows: 1
   :widths: 18 82

   * - Code
     - Content description (what it means for you)
   * - VC2TDI10S01
     - Investigate how hardware and software manage, control and secure access to data in networked
       digital systems. *(Computing and cybersecurity)*
   * - VC2TDI10D05
     - Select and use emerging digital tools and advanced features to create and communicate
       interactive content for a diverse audience. *(AR project)*
   * - VC2TDI10C01
     - Define and decompose real-world problems, taking into account functional and non-functional
       requirements and by interviewing and surveying stakeholders to identify needs.
       *(AR project planning, GUI project)*
   * - VC2TDI10C02
     - Design algorithms involving logical operators and represent them as flowcharts and pseudocode,
       and validate algorithms and programs by comparing their output against a range of test cases.
       *(Algorithms, selection, iteration)*
   * - VC2TDI10C03
     - Design, modify and prototype the user interface and user experience of a digital system;
       generate, communicate and critically evaluate alternative designs against design criteria.
       *(Designing the AR experience, Tkinter GUIs)*
   * - VC2TDI10C04
     - Implement, modify and debug modular programs, applying selected algorithms and data structures,
       including in an object-oriented programming language. *(Functions, lists, dictionaries, Tkinter)*
